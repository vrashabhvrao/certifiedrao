Digital Electronics FAQ

VLSI and Verilog learning notes

This section gives search engines and students a clearer map of the topics covered here: VLSI basics, boolean algebra, truth tables, Verilog assignments, 2's complement arithmetic, and electronics lab utilities.

What is this VLSI portfolio about?

This portfolio documents Vrashabh V Rao's learning in VLSI design, digital electronics, semiconductor fundamentals, boolean logic, Verilog, number systems, and electronics lab basics.

Can I generate truth tables for boolean expressions?

Yes. The Boolean Truth Table and Verilog Helper accepts expressions using A, B, C, D, AND, OR, XOR, NOT, and parentheses, then generates the full truth table and canonical minterms.

Does the site help with Verilog learning?

Yes. The Logic Lab converts a boolean expression into a simple Verilog assign statement that students can copy, test, and adapt while practicing combinational digital design.

Which electronics tools are included?

The site includes a logic gate simulator, 8-bit radix converter, 2's complement helper, resistor color code calculator, truth table generator, and Verilog assign generator.
